## Processo e critérios

- Antes de avaliar, o revisor deve ler o artigo e identificar suas principais contribuições. A página recomenda um ambiente virtual compatível e diz que recursos adicionais devem constar no apêndice do artefato.
- O processo descrito tem escolha dos trabalhos pelos revisores e, depois, revisão conforme os requisitos de cada selo.
- **Disponível (D):** código/dados em repositório estável; README com objetivo, estrutura, selos pretendidos, ambiente, dependências, segurança, instalação, teste mínimo, experimentos e licença.
- **Funcional (F):** código/artefato executável e funcionalidades observáveis; README com dependências e versões, ambiente, instruções de instalação/execução e exemplo mínimo.
- **Sustentável (S):** código modular, organizado, inteligível, documentado minimamente e com reivindicações do artigo identificáveis.
- **Reprodutível (R):** revisor deve conseguir reproduzir as principais reivindicações do artigo; devem existir instruções para executá-las e descrição de como os experimentos geraram os resultados apresentados.
- A revisão de cada artefato deve justificar brevemente cada selo atribuído ou negado após a avaliação.

## Implicação para a T8

O teste funcional do Mininet-GUI depende de emulação real e interface utilizável. Para R, deve-se vincular os casos de uso e contribuições do artigo a procedimentos e resultados observáveis, distinguindo um teste mínimo de reprodução das reivindicações.
